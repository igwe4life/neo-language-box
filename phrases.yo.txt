# Phrase-override table for English -> Yoruba.
#
# The translation model was trained on a tiny parallel corpus (~4k sentences
# from Ubuntu/GNOME localisation) with the rest back-translated. That makes it
# strong on sermon-length prose but weak on short, high-frequency courtesies -
# it mistranslates "Good morning everyone" as "nobody who doesn't enjoy the
# morning", and "Bye-bye" as "bread". Force overrides here.
#
# FORMAT
#   Case-insensitive.  english text = yoruba text
#   One rule per line. Lines starting with # are ignored.
#   Matched on the WHOLE input first, then longest-match substring.
#   Punctuation at the end of the input is preserved.
#
# Add more as you find them - `python run.py translate "..."` is the fastest
# way to test one.

Good morning              = Ẹ káàárọ̀
