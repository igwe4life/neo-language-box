Neo Language Box

Setup guide - install, first service, getting listeners connected

1What you need

The installer ships as four files. All four have to sit in the same folder before you run anything - the installer reads the others as it goes.

NeoLanguageBoxSetup.exe - run this one
NeoLanguageBoxSetup-1.bin
NeoLanguageBoxSetup-2.bin
NeoLanguageBoxSetup-3.bin - these three travel with it

Put all four in one folder (a fresh folder on the Desktop is fine), then double-click NeoLanguageBoxSetup.exe. If the .bin files aren't beside it, the install will stop partway through and tell you one is missing.

2Installing

  1. Windows may show a blue "Windows protected your PC" screen the first time, since this isn't a signed, store-published app. Click More info, then Run anyway.
  2. The installer doesn't need admin rights and doesn't ask for them. Click through the wizard - the defaults are fine for almost everyone.
  3. Leave the desktop shortcut option checked unless you'd rather launch it from the Start Menu only.
  4. Click Install. This copies about 5 GB, so it can take a few minutes depending on the machine.
Already have an older version installed? This installs as an upgrade over it automatically - same shortcuts, same install folder, old leftover files cleaned up. You don't need to uninstall first.

3First launch

The app opens to a loading screen while it checks every language model file against the list it shipped with. On a normal first run this takes well under a minute.

If it just works
You'll land on the main dashboard automatically. Nothing else to do here - skip to step 4.
If it says files are missing or damaged
It'll name exactly which ones. This usually means the install was interrupted or copied incompletely - reinstalling fixes it.

Windows Firewall may ask for permission the first time the app starts its server - click Allow. If you click Deny by mistake, phones on the Wi-Fi won't be able to reach it.

4The dashboard, quickly

Everything you need during a service lives on one screen.

Audio Source
Pick "System Audio" to capture whatever the room's sound system plays, or a specific microphone.
Control
The big button starts and pauses listening. Nothing is translated while paused.
Live Transcription
Shows what's being heard and translated in real time, so you can confirm it's working before anyone's listening.
Connected Listeners
A live count of phones currently on the listener page.

Settings (the gear icon)

  • Event name - shown as the headline on the listener page itself (e.g. "Sunday Service").
  • Listener URL - the short link you'll share, like /neo/your-event. Auto-filled from the event name, or set your own.
  • Share anonymous usage stats - on by default. Sends an install count and per-service listener numbers, nothing else. Turn it off here any time.

Manage Languages

Turn individual languages on or off for this service. Fewer active languages means less work per sentence, which can help on an older laptop.

5Getting listeners connected

  1. Click the QR code icon to bring up a code for the current listener URL. Point it at a screen, or share the link directly.
  2. A listener scans it or opens the link on their own phone - no app to install, it opens in their regular browser.
  3. They pick their language once; it's remembered on that phone for next time.
Phones will show a "not secure" warning the first time they visit. That's expected - the app generates its own certificate so the connection is still encrypted on your Wi-Fi, it's just not from a public certificate authority. Tell listeners to tap Advanced, then Proceed anyway (wording varies slightly by phone). They only see this once per phone.

Listeners are on the same Wi-Fi network as the laptop running Neo Language Box - there's no internet requirement for the translation itself to work.

6If something's not working

Phones can't reach the listener page
Check the Windows Firewall prompt was allowed. Confirm phones are on the same Wi-Fi network as the laptop, not a guest network that isolates devices from each other.
No audio, text only
Listeners can mute/unmute from the page itself. If a specific language has no voice yet, that listener gets text plus their own phone's built-in voice automatically - not a bug.
A listener reports a problem
They can flag it directly from their phone (the flag icon on the listener page) - wrong translation, bad audio, or something else. It shows up on your dashboard.
Translation looks stuck
Check Control isn't paused, and that Audio Source matches where the sound is actually coming from.

7Uninstalling

Use Windows' own Settings > Apps, or the shortcut in the Start Menu folder. This removes the app and its language models; nothing is left behind.
