Neo Language Box

Platform overview — prepared for management review

Neo Language Box is a self-contained Windows desktop application that listens to a live speaker and produces spoken and written translations in real time, in multiple languages at once. It runs entirely on one laptop — no cloud service, no internet connection, and no external AI subscription required to operate.

What's actually under the hood
Application
Python desktop app — built with PyInstaller and an Inno Setup installer. One .exe; no admin rights required to install.
Speech recognition
Open-source speech-to-text models — run locally on the laptop's own CPU, no cloud call involved.
Translation
Specialised machine-translation models — purpose-built for translation, not a general chatbot-style AI. Each language runs its own lightweight model.
Voice synthesis
Offline text-to-speech models — one trained voice per target language, also generated locally.
Delivery to listeners
Local Wi-Fi + web server — listeners open a link in their phone's own browser. Nothing to install on their end.
Why this approach, not a cloud AI service
Private by design
Audio and translated text never leave the building — nothing is sent to a third-party server.
No recurring cost
Translation and voice generation aren't metered. One install, no per-minute or per-word billing.
Works offline
No dependency on venue internet quality or a vendor's uptime — it runs the same with no connection at all.
Prepared for an internal management presentation. Current build translates into 12 languages live (plus the original English), with more addable as voice models are validated.
